# Добавление выгрузки для банка

### Вступление
Проект использует отдельные классы (Exporter) для каждого банка при выгрузке данных из БД. Классы находяться в дирректории *app/Exports/*

### Генерация классов
Для создания нового класса Exporter вы можите использовать команду 
```sh
    php artisan make:exporter <Наименование Класса>
```
Это создаст новый Exporter класс с необходимыми зависимостями.

Или вы можете просто создать класс вручную
```php
<?php

namespace App\Exports;

use App\Classes\Exporter;

class <Наименование Класса> extends Exporter{

    public function __construct()
    {
        parent::__construct(...func_get_args());
    }

    public function save()
    {
        // Код формирования файла
    }
}
```

### Свойства и методы классов
Классы, расширяющие Exporter, содержат следующие методы:
  * setFileName(string $name) - устанавливает имя конечного файла. Рекомендуется использовать данный метод в конструкторе класса.
  * setFilePath(string $path) - устанавливает путь до конечного файла. Рекомендуется использовать данный метод в конструкторе класса.
  * delete() - удалить файл, а так же записи в БД о нем.
  * moveToDisk(string $disk, string|null $path = null, string|null $fileName = null) - Перемещает файл на указанный диск. Есть возможность указать рассположение и имя файла на новом диске. Возможные диски:
  * * local - рассположение в том же месте, где и проект, по пути *storage/app/private*
  * * ftp - удаленный ftp server. Данные для подключения указываются в .env файле
  * * public - публичная папка проекта *ВНИМАНИЕ* файлы в этой директории доступны по URL.

При написании класса, могут понадобиться следующие свойства:
  *  $raport - запись о текущем файле в БД.
  *  $bank - запись о банке.
  *  $event - запись о событии.
  *  $startBy - запись о порльзователе, зупустившем вычисления.
  *  $raport_npp - Строка из 5 символов, содержащая номер файла по порядку. Обнуляется ежегодно 01.01 00:00
  *  $recipients - содержит коллекцию получателей для данного банка.

### Написание классов
Каждый класс должен реализовывать публичный метод save(), в котором описывается создание документа и который возвращает экземпляр класса. Например
```php
public function save()
    {
        $this->f = fopen(Storage::disk('local')->path($this->save_path . '/' . $this->file_name), 'w');

        $this->writeStart();
        $this->writeContent();
        $this->writeEnd();

        return $this;
    }
